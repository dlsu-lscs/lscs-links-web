### [22:41:16 +08:00] Fix CORS & 502 Bad Gateway

**Problem:**  
Client-side API requests were failing with CORS errors ("Access-Control-Allow-Origin" missing) and 502 status codes. The frontend was attempting to fetch directly from the backend URL (`https://links.api.dlsu-lscs.org`), bypassing the Next.js proxy.

**Solution:**  
Refactored `fetchLinks` and related services to use relative paths (e.g., `/admin/links`) when executing on the client side. This routes requests through the Next.js Rewrite/Proxy layer, ensuring server-to-server communication which avoids CORS restrictions.

**Affected Files:**

- `src/services/links.ts`

**Notes:**

- `NEXT_PUBLIC_SERVER_API_URL` is still required for generating shareable links in the UI but is no longer used for direct `fetch` calls in the browser.
